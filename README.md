# Namma Shaale Inventory App

## Overview
Namma Shaale Inventory is an Android application developed to manage school assets efficiently. The app helps schools track inventory items, monitor asset conditions, and generate PDF reports.

## Features
- User Login and Create Account
- School ID Authentication
- Add New Assets
- View Asset Details
- Asset Condition Tracking
- Upload Asset Images
- Generate PDF Reports
- Dashboard Statistics
- Logout Functionality

## Technologies Used
- Kotlin
- Android Studio
- Room Database
- XML
- SharedPreferences

## Modules
1. Splash Screen
2. Login Screen
3. Create Account
4. Dashboard
5. Add Asset
6. View Assets
7. PDF Report Generation
